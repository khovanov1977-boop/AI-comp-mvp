# Готовые персонажи

Каталог из десяти образцов определён в `apps/api/app/example_catalog.py`. Состав: Мария, Даниил, Арина, Артём, Тамара, Саша, Виктор, Ирина, Виктория и Анна. Порядок первых четырёх для главной витрины пока не выбран; страница примеров показывает всех по алфавиту без выделения.

Для каждого образца хранится ровно три изображения: `face.png`, `body.png`, `clothing.png`. Каждый этап выполнен одним запросом к Venice и сразу принят. Фигура использует лицо как референс, одежда — фигуру. Журнал каждой генерации находится в `manifest.json` рядом с файлами. Скрипт не делает автоматических повторов после ошибки или неизвестного исхода:

```powershell
cd apps/api
.venv\Scripts\python.exe -m scripts.generate_example_characters --execute --confirm-paid VENICE_PAID_EXAMPLE_CHARACTERS --max-new-requests 30
```

Скрипт пропускает уже сохранённые корректные файлы. Перед ручным повтором запроса со статусом `unknown` проверьте возможное списание и наличие результата у провайдера. Не удаляйте готовые файлы ради новых вариантов: договорённость для образцов — один вариант на этапе.

После входа пользователь видит каталог на `/examples` и может создать личную копию. Копирование сохраняет анкету, три изображения и выбранный образ, но не переносит чужие чаты или память и не расходует лимит генерации изображений аккаунта. Файлы копии лежат в личном хранилище персонажа и удаляются вместе с ним. Сайт не публикуется автоматически.
