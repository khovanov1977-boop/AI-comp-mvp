## Что умеет продукт

- Создание личного персонажа с ролью, характером, стилем общения, биографией, границами, обращением к пользователю и голосом. Внешность создаётся по этапам «лицо → фигура → одежда»; позднее её и анкету можно менять.
- Переписка с историей, памятью и эмоциональным состоянием, зависящим от роли; ролевые игры, текстовые и голосовые сообщения, генерация фото и два сценария видео.
- Личная медиатека, сгруппированная по персонажам; просмотр полноразмерных изображений и видео с перелистыванием.
- Каталог готовых примеров: Анна, Арина, Артём, Виктор, Виктория, Даниил, Ирина, Мария, Саша и Тамара. У каждого по три исходных изображения: `face.png`, `body.png`, `clothing.png`. Личная копия примера не расходует лимит генерации изображений. Порядок первых четырёх для витрины ещё не выбран.
- Прослушивание подготовленных голосовых образцов из файлов приложения, без нового вызова синтеза при каждом прослушивании готового файла.

Локальные аккаунты и файлы при публикации не переносились. Это не означает, что рабочая база сейчас пустая: на публичном сайте уже могут быть реальные аккаунты и данные.

## Лимиты и расходы

| Ресурс | Лимит для одного аккаунта за всё время |
| --- | ---: |
| Созданные изображения | 10 результатов |
| Запросы видео | 3 |
| Текстовые ответы персонажей | 500 |
| Голосовые ответы персонажей | 50 |

Счётчики не обнуляются при удалении чата или персонажа. Открытая регистрация позволяет завести другой аккаунт с новым набором лимитов. Общий лимит `$30` отменён владельцем: значения глобальных ограничителей генераций в текущей конфигурации отключены. Баланс Venice остаётся фактической границей расходов; владелец подтвердил, что Auto Top-Up выключено. Это состояние внешнего аккаунта следует перепроверять в Venice при необходимости. Актуальную цену видео интерфейс запрашивает перед отправкой задания; исторические цены из старых заметок не следует считать текущими.

## Модели и провайдер

Таблица отражает действующие переменные серверного `.env.production` и выбор модели в коде на дату снимка. `compose.production.yml` принудительно выбирает Venice для соответствующих провайдеров.

| Задача | Модель |
| --- | --- |
| Переписка | `gemma-4-uncensored`; запасные по порядку: `venice-uncensored-1-2`, `venice-uncensored-role-play` |
| Распознавание речи | `openai/whisper-large-v3` через Venice |
| Озвучивание | `tts-gemini-3-1-flash` через Venice |
| Лицо | `grok-imagine-image-2-0` |
| Фигура | `grok-imagine-image-2-0-edit` (этап редактирования по референсу) |
| Одежда | `qwen-edit-uncensored` |
| Фото в чате | `qwen-edit-uncensored` |
| Оба сценария видео | `wan-3-0-reference-to-video` |

Для видео интерфейс использует 480p и 5 секунд. Описание действий перед генерацией переводится на английский, реплики в кавычках сохраняют язык пользователя. Если обращаться напрямую к API, сверяйте параметры запроса: умолчания схемы API могут отличаться от пресета интерфейса. В прежнем обсуждении лицо и фигура кратко назывались одной моделью; фактический этап фигуры использует отдельную edit-модель, как показано выше.

## Архитектура и данные

```text
Пользователь → HTTPS / Caddy (80, 443)
                    ├─ /api/* → FastAPI (api:8000) → PostgreSQL (db:5432)
                    │                         ├─ Venice API
                    │                         └─ /app/data: личные медиа и кэш голосов
                    └─ остальные пути → Next.js (web:3000)
```

На VPS один Docker Compose проект `ai-companion`: `proxy` (Caddy), `web` (Next.js), `api` (FastAPI), `db` (PostgreSQL 16). База находится во внутренней сети контейнеров и не опубликована на внешнем порту. `NEXT_PUBLIC_API_URL=/api`. Docker запускается при старте сервера, у сервисов `restart: unless-stopped`. Сессии используют защищённую HttpOnly cookie сроком 30 дней. Публичные `/api/debug`, `/api/docs`, `/api/redoc` и `/api/openapi.json` закрыты Caddy.

Постоянные тома Compose: `postgres_data` (БД), `app_data` (медиа и голосовые файлы), `caddy_data` (включая данные сертификатов), `caddy_config`. Удаление томов приведёт к потере соответствующих данных. Часть исходных изображений образцов и подготовленных голосовых превью входит в репозиторий. Таблицы приложения создаются/дополняются при запуске API; отдельная система миграций сейчас не выделена.
